Nuxt I18n Micro

Small, fast i18n for Nuxt. JSON translations loaded per page, localized routes generated at build time, SEO tags without extra code.
Get startedGitHub

Why Nuxt I18n Micro

Only the translations a page needs, routes resolved before the first request, and SEO tags out of the box.
  • One dictionary per page
    A page loads its own JSON plus the shared root keys, fetched on demand and never inlined into the HTML payload.
  • Routes built at build time
    Four prefix strategies, localized paths, redirects and 404s from one route model, with no runtime route matching.
  • SEO without extra code
    Canonical URLs, hreflang alternates, html lang and dir, and og:locale on every localized page.
  • Same core, more frameworks
    Vue, React, Preact, Solid, Astro, Node and VitePress share the translation runtime and file layout.

Up and running in two steps

Install the module, list your locales, and put a JSON file next to each page. Dev mode creates the empty files for you.
Getting startedMigrate from @nuxtjs/i18n
pnpm add nuxt-i18n-micro

npm install nuxt-i18n-micro

yarn add nuxt-i18n-micro

bun add nuxt-i18n-micro
nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
  },
})
