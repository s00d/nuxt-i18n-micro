API Reference ​

Runtime API ​

  • Methods — $t, $ts, $_t, $_ts, locale switching, routing helpers
  • Events — i18n:register, i18n:beforeLocaleSwitch, i18n:afterLocaleSwitch
  • Translations and Cache — TranslationStorage, payload loading, $clearCache

Server middleware ​

Server handlers use dedicated middleware (not the client $t helpers):

  • useTranslationServerMiddleware — translate in API routes and server handlers
  • useLocaleServerMiddleware — read detected locale and metadata

See the full Server-Side Translations guide for setup, locale detection priority, and examples.
