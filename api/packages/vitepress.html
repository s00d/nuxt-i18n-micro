@i18n-micro/vitepress

Exported API of @i18n-micro/vitepress, generated from the source.

VitePress bindings for i18n-micro — runtime dictionaries, MD components, and locale switcher.

Entry points: @i18n-micro/vitepress, @i18n-micro/vitepress/config, @i18n-micro/vitepress/node, @i18n-micro/vitepress/theme.

Functions

createI18n

Universal VitePress i18n: Vue plugin + path helpers + enhanceApp sync. Path methods are the router adapter’s own functions (no wrapper layer).

function createI18n(options: CreateI18nOptions): CreateI18nResult

See CreateI18nOptions · CreateI18nResult

getLocaleFromPath

Detect i18n locale code from a URL path (prefix_except_default). Path prefixes are VitePress locale keys; return value is the i18n code. Pass base when the path may include VitePress site.base (SSG).

function getLocaleFromPath(
  path: string,
  localeCodes: string[],
  defaultLocale: string,
  localeKeyToCode?: Record<string, string>,
  base?: string,
): string

messagesFromGlob

Tiny helper if you still prefer import.meta.glob instead of defineI18nTheme. Only unwraps Vite module namespaces — dictionaries with a default key stay intact.

function messagesFromGlob(
  modules: Record<string, { default: Translations; } | Translations>,
): Record<string, Translations>

See Translations

routeNameFromPath

Route name for page-scoped dictionaries (/guide/demo → guide-demo). Strips VitePress URL prefixes (keys), not only raw i18n codes.

When defaultLocale is omitted (legacy 2-arg call), any segment that matches a listed locale code is stripped — callers must not rely on localeCodes[0] as default.

function routeNameFromPath(
  path: string,
  localeCodes: string[],
  defaultLocale?: string,
  localeKeyToCode?: Record<string, string>,
  base?: string,
): string

stripSiteBase

Strip VitePress site.base from a path. Leaves query/hash intact. No-op when base is missing or /.

function stripSiteBase(path: string, base?: string): string

withI18n

VitePress config helper: virtual modules + optional i18nRouting / SEO head.

Registers:

  • virtual:i18n-micro/config
  • virtual:i18n-micro/messages (from translationDir, default locales/)

By default also sets themeConfig.i18nRouting (pass i18nRouting: false to skip). Pair with defineI18nTheme(DefaultTheme) from @i18n-micro/vitepress/theme. Import from @i18n-micro/vitepress/config (Node / config files only).

function withI18n<T extends VitePressUserConfigLike>(
  config: T,
  options: WithI18nOptions,
): T

defineI18nTheme

Zero-boilerplate theme wiring. Requires withI18n(...) in .vitepress/config so virtual config + messages modules exist.

Uses static virtual:i18n-micro/* imports so VitePress SSG can rewrite them. Import this helper from @i18n-micro/vitepress/theme (not the root entry) so Node config evaluation never loads virtual modules.

function defineI18nTheme<T extends Theme>(base: T, options?: DefineI18nThemeOptions): T
